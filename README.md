# آزادیار (AzadiYar) 🕊️
### ابزار هوشمند دسترسی به اینترنت بین‌المللی، جمع‌آوری کانفیگ و عیب‌یابی شبکه

آزادیار (AzadiYar) یک نرم‌افزار متن‌باز، پیشرفته و مستقل برای اندروید است که با هدف ارزیابی مسیرهای ارتباطی، جمع‌آوری خودکار کانفیگ‌های عمومی، عیب‌یابی چندلایه‌ای شبکه و انتخاب خودکار سالم‌ترین مسیر خروجی توسعه یافته است.

---

## 🌟 ویژگی‌های کلیدی

1. **موتور اتصال و VpnService اندروید:**
   - پیاده‌سازی کامل سرویس `AzadiVpnService` با مدیریت رابط تونل TUN
   - رمزنگاری مسیر ترافیک، مسیریابی شبکه و حفاظت از سوکت‌ها (`protect(socket)`)
   - بازیابی خودکار اتصال در صورت قطع (Auto-Recovery)

2. **پشتیبانی واقعی از انواع پروتکل‌ها:**
   - **VLESS** (با پشتیبانی از TLS، Reality، WebSocket، gRPC، TCP)
   - **VMess** (تجزیه استاندارد JSON Base64)
   - **Trojan** (پشتیبانی از SNI و گواهی TLS)
   - **Shadowsocks** (قالب SIP002 و استانداردهای متداول)
   - **SOCKS5** و **HTTP Proxy**

3. **سیستم جامع جمع‌آوری کانفیگ از منابع عمومی:**
   - مخازن عمومی GitHub و پیوندهای اشتراک باز
   - دانلود کنترل‌شده جریانی (محدودیت امنیتی ۲ مگابایت جهت جلوگیری از بارگذاری مخرب یا سرریز حافظه)
   - حذف هوشمند تیکه‌های تکراری با هش نرمال‌شده SHA-256 (محافظت از افشای اطلاعات محرمانه)
   - نمایش سهم درصدی هر منبع از کل کانفیگ‌ها
   - امکان افزودن، ویرایش، حذف و خاموش/روشن کردن دستی منابع توسط کاربر

4. **سیستم تست و رتبه‌بندی کیفی کانفیگ‌ها:**
   - مرحله ۱: اعتبارسنجی ساختاری
   - مرحله ۲: بررسی در دسترس بودن Endpoint و زمان رفت‌وبرگشت TCP (پینگ واقعی)
   - مرحله ۳: دست‌تکانی TLS و آزمایش گواهی امنیتی
   - مرحله ۴: الگوریتم امتیازدهی کیفی (ترکیب پینگ، پایداری تاریخی و نرخ موفقیت)

5. **عیب‌یابی جامع و تفکیک اختلالات شبکه:**
   - تشخیص تفاوت بین قطعی شبکه فیزیکی، اختلال DNS، پرتال لاگین (Captive Portal)، مسدودی مستقیم و دسترسی خارجی
   - گزارش صادقانه و بدون ادعاهای کاذب در قالب وضعیت‌های روشن و راهنمای فارسی

6. **پشتیبانی از پل‌های واسط و تونل DNS (dnstt):**
   - تنظیمات Clean IP، پورت و SNI جایگزین
   - خردسازی بسته‌های ClientHello (TLS Fragmentation) جهت عبور از سامانه‌های DPI
   - ماژول تونل DNS با شفاف‌سازی پیشنیازها (نیازمند سرور اختصاصی dnstt و دامنه دارای NS)

## 📱 معماری فنی

- **زبان:** Kotlin
- **رابط کاربری:** Jetpack Compose + Material 3 (RTL بومی فارسی)
- **پایگاه داده:** Room Database (`AzadiDatabase`, `ConfigDao`, `ConfigSourceDao`, `DiagnosticDao`)
- **همزمانی:** Kotlin Coroutines & Reactive Flow
- **شبکه:** OkHttp & Android Network Sockets

## 🛠️ ساخت و انتشار خودکار (GitHub Actions)

پروژه مجهز به گردش‌کار خودکار در مسیر `.github/workflows/android.yml` است:
1. دریافت خودکار کدها
2. راه‌اندازی JDK 17
3. اجرای تست‌های واحد و Robolectric (`gradle testDebugUnitTest`)
4. ساخت بسته APK نهایی (`gradle assembleDebug`)
5. ذخیره و آپلود خودکار فایل APK در بخش Artifacts گیت‌هاب جهت دانلود و نصب مستقیم روی گوشی.
